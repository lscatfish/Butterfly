# V6.3 C_L/C_D 公式改进实验记录

> 日期：2026-06-05

## 1. 背景

v6.1/v6.2 使用混合模型：
- |α| ≤ 40°: Dickinson 经验 C_L/C_D
- 40° < |α| ≤ 70°: smoothstep 过渡
- |α| > 70°: 平板 C_L=(C_N90/2)sin(2α), C_D=C_N90·sin²(α), C_N90=2.0

问题：C_N90=2.0 使 C_D_max=2.0，远低于昆虫翅膀实测 C_D_max≈3.0-3.5。

## 2. 实验 1：Dickinson 全范围延伸

将 Dickinson 公式直接用于全范围（无 clamp/过渡）：

```
C_L = 0.255 + 1.58·sin(2.13α − 7.2°)
C_D = 1.92 − 1.55·cos(2.04α − 9.82°)
```

### 结果：失败

| 配置 | 混合模型 L/W | Dickinson L/W | 变化 |
|------|-------------|--------------|------|
| α_f=60°/α_b=10° | 1.145 | 0.173 | -85% |
| α_f=55°/α_b=12° | 0.962 | 0.168 | -83% |
| α_f=45°/α_b=10° | 0.615 | 0.291 | -53% |

### 根因

Dickinson 的 sin(2.13α−7.2°) 周期为 360/2.13=169°，不是 180°。在 |α|>80°：
- sin(2.13×(−80°)−7.2°) = sin(−177.6°) ≈ −0.042, C_L≈+0.19
- 物理正确应为 C_L≈−0.3~−0.6（负升力）

符号在极端攻角出错。

## 3. 实验 2（计划）：LEV 理论 + Lee 公式

文献 [32]（JRSI, 2017）给出 LEV 稳定状态升力系数：

```
C_L = A·sin(2α)
A = C_Lα/2
C_Lα = π·AR / (1 + √((π·AR/a₀)² + 1))
```

蝴蝶 AR≈1.4, a₀=2π: C_Lα≈1.98, **A≈0.99**

文献 [24]（机器人, 2025）给出全范围阻力系数：

```
C_D = C_D0 + A_D·(1−cos(2α))
```

### 实施计划

在 α=60° 处匹配 Dickinson 值实现连续过渡：

```
|α| ≤ 60°: Dickinson 经验公式（含 LEV 增强，C_L_peak≈1.8）
|α| > 60°: C_L = A_adj·sin(2α), C_D = C_D0 + A_D·(1−cos(2α))
           A_adj, C_D0, A_D 由 α=60° 连续条件确定
```

在 α=60°:
- Dickinson: C_L=1.616, C_D=2.515
- LEV: A_adj·sin(120°)=A_adj·0.866=1.616 → **A_adj=1.866**
- Lee: C_D0+A_D·(1−cos(120°))=C_D0+1.5·A_D=2.515
  - 且 α=0°: C_D=C_D0=Dickinson C_D(0°)=0.393
  - → 0.393+1.5·A_D=2.515 → **A_D=1.414**

### 全范围特性

| α | C_L (LEV混合) | C_D (Lee混合) | C_L(物理) | C_D(物理) |
|---|--------------|--------------|----------|----------|
| 0° | 0.057 | 0.393 | ~0 | ~0.4 |
| 45° | 1.835 | 1.702 | 正升力 | — |
| 60° | 1.616 | 2.515 | ← 匹配点, 连续 | — |
| 80° | 0.642 | 3.221 | 小正升力 | — |
| 90° | 0.000 | 3.221 | **归零** ✓ | 最大阻力 ✓ |
| 100° | -0.642 | 3.221 | 负升力 ✓ | — |
| 120° | -1.616 | 2.515 | 负升力 ✓ | — |

C_D_max=3.221，接近昆虫翅膀实测 (~3.0-3.5)，比平板模型 (2.0) 更合理。
