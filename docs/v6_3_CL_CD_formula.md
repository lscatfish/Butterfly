# V6.3 LEV/Lee C_L/C_D 公式实验

> 日期：2026-06-05 | 版本：v6.3

## 1. 背景

v6.1/v6.2 使用混合模型：
- |α| ≤ 40°: Dickinson 经验 C_L/C_D
- 40° < |α| ≤ 70°: smoothstep 过渡
- |α| > 70°: 平板 C_L=(C_N90/2)sin(2α), C_D=C_N90·sin²(α), C_N90=2.0

**问题**：C_N90=2.0 → C_D_max=2.0，远低于昆虫翅膀实测 C_D_max≈3.0-3.5。
平板模型在高攻角压低了阻力 → 上拍负升力被低估 → L/W 虚高。

## 2. 实验 1：Dickinson 全范围延伸（失败）

### 方法

将 Dickinson 公式直接用于全范围（无 clamp/过渡）：
```
C_L = 0.255 + 1.58·sin(2.13α − 7.2°)
C_D = 1.92 − 1.55·cos(2.04α − 9.82°)
```

### 结果

| 配置 | 混合 L/W | Dickinson L/W | 变化 |
|------|---------|--------------|------|
| α_f=60°/α_b=10° | 1.145 | 0.173 | **-85%** |
| α_f=55°/α_b=12° | 0.962 | 0.168 | -83% |
| α_f=45°/α_b=10° | 0.615 | 0.291 | -53% |

### 根因

Dickinson 的 sin(2.13α−7.2°) 周期为 169°（不是 180°）。|α|>80° 时符号错误：
- α=−80°: C_L(Dickinson)≈+0.19, 物理应为≈−0.3~0.6

## 3. 实验 2：LEV 理论 + Lee 公式（成功）

### 方法

文献 [32]（JRSI, 2017）：LEV 稳定状态 C_L = A·sin(2α)
文献 [24]（机器人, 2025）：全范围 C_D = C_D0 + A_D·(1−cos(2α))

在 α=60° 匹配 Dickinson 实现连续：

```
|α| ≤ 55°: Dickinson 经验（LEV 增强，C_L 峰值 1.84 @ 46°）
55°-65°:  smoothstep 过渡
|α| ≥ 65°: C_L = 1.866·sin(2α), C_D = 0.393 + 1.414·(1−cos(2α))
```

匹配系数计算：
- C_L: 1.616/sin(120°) = **1.866**
- C_D: C_D(0°)=0.393, C_D(60°)=2.515 → **A_D=1.414**

### 全范围特性

| α | C_L | C_D | 验证 |
|---|-----|-----|------|
| 0° | 0.057 | 0.393 | 接近零升力 |
| 30° | 1.574 | 0.953 | — |
| 45° | 1.835 | 1.702 | C_L 峰值 ≈1.84 |
| 60° | 1.616 | 2.515 | ← **匹配点, 连续** |
| 80° | 0.642 | 3.221 | C_L↓, C_D 增长 |
| 90° | **0.000** | **3.221** | C_L=0 ✓, C_D_max=3.22 ✓ |
| 100° | -0.642 | 3.221 | C_L 自动变号 ✓ |
| 120° | -1.616 | 2.515 | 对称正确 ✓ |

C_D_max=3.221，**显著优于平板模型 (2.0)**，接近昆虫实测 (~3.0-3.5)。

## 6. 参数规律

```
α_f ↑ → L/W ↑（前翅大安装角主导升力）
α_b ↑ → L/W ↓（后翅参与升力 → 正向力矩 ↑ → pitch ↑）
L/W ∝ α_f − 3.5·α_b (粗略线性趋势)

最优模式不变：α_f 大 + α_b 小
v6.3 最佳点 α_b=8° 比 v6.2 的 α_b=10° 更小 → 新公式高阻力要求更极端的非对称
```

## 7. 结论

v6.3 的 LEV/Lee 公式解决了三个问题：
1. **C_D 物理正确**：C_D_max=3.22，不再被平板模型低估
2. **C_L 全范围正确**：sin(2α) 在 90° 归零，>90° 自动变号
3. **与 Dickinson 连续**：60° 匹配，无 jump

L/W=0.943 距悬停 1.0 仅差 6%，且公式全部物理可解释。
