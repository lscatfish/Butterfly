## 1. 实验演进路线

```
v6: 刚性翅膀 + 非对称 α_install 扫描 (144 组)
│   发现：正升力可达 L/W=1.48，但俯仰全部发散 (>360°~数千°)
│   根因：M_aero 时间均值不为零，重力恢复力矩不足以抵消
│
├─ v6.1: 引入气动俯仰阻尼
│   │  Δα = θ̇_p × x_wing / U → 前后翅力差异 → 恢复力矩
│   │  发现：L/W=1.145, peak θ=45.7°, 10s 全稳定
│   │  问题：α_eff 均值 ~80°，100% 在平板失速区，未使用 LEV 经验公式
│   │
│   └─ v6.2: 降低 α_install → LEV 经验公式有效范围
│       发现：L/W=0.615, peak θ=35.3°, 物理正确
│       权衡：L/W 下降但物理机制可信
```

## 2. 物理模型

### 2.1 攻角计算（刚性翅膀）

```
α_geom = α_install + ψ = α_install + φ + θ_p
下拍 (φ_dot ≤ 0): α_eff = +α_geom + Δα_damp
上拍 (φ_dot > 0): α_eff = -α_geom + Δα_damp
Δα_damp ≈ atan(θ̇_p × x_wing / U)  ← v6.1 新增
```

### 2.2 C_L/C_D 混合模型

```
|α| ≤ 40°: 100% 经验公式 (Sane & Dickinson 2002)
            C_L = 0.255 + 1.58·sin(2.13α - 7.2°)
            C_D = 1.92 - 1.55·cos(2.04α - 9.82°)
            → 含 LEV 效应，峰值 C_L ≈ 1.8 @ α≈45°

40° < |α| ≤ 70°: smoothstep 过渡 (3t²−2t³)
|α| > 70°: 100% 平板模型
            C_L = C_N90/2 · sin(2α),  C_N90 = 2.0
            C_D = C_N90 · sin²(α)
            → 失速后压力主导，C_L(90°)≈0, C_D(90°)≈2.0
```

### 2.3 力投影公式

```
F_wing = F_trans + F_AM + F_clap
Fx = sin(ψ) × (sign_Ω × D_eff − L_eff)
Fz = cos(ψ) × (L_eff − sign_Ω × D_eff)

下拍 (sign=−1): Fz = cos(ψ)×(L + D) → 升力+阻力都贡献向上升力
上拍 (sign=+1): Fx = sin(ψ)×(D − L) → D>L 时产生前向推力
```

### 2.4 俯仰动力学

```
I_yy · θ̈_p = M_aero + M_gravity + M_damp + M_aero_damp

M_aero    = 2 × (−x_front × Fz_front − x_back × Fz_back)
          = 0.05 × (Fz_back − Fz_front)  [N·m]
M_gravity = −mgd_cg · sin(θ_p)         max ≈ ±2940 μN·m
M_damp    = −c_damp · θ̇_p              c_damp = 5×10⁻⁴
M_aero_damp: v6.1 新增，来自 θ̇_p×x_wing 对 α_eff 的修正
             当 θ̇_p > 0: 前翅 α↑, 后翅 α↓ → M < 0 (恢复)
             当 θ̇_p < 0: 前翅 α↓, 后翅 α↑ → M > 0 (恢复)
```

## 3. v6 初始扫描（t=1.5s, 144 组）

### 3.1 参数空间

| 维度 | 范围 |
|------|------|
| α_install_front | 10°, 20°, 30°, 40°, 50°, 60° |
| α_install_back | 10°, 20°, 30°, 40°, 50°, 60° |
| 相位 | 同相 (0), 反相 (π) |
| 模型 | fixed, moving (Vx) |

### 3.2 关键发现

1. **对称安装 (α_f=α_b)，所有组合净升力为负** — 不对称是必要条件
2. **反相 180° 无法稳定** — 正升力组合的俯仰全部 >60°
3. 报告中的 "|Pitch|" 仅统计后半段稳态 `max|θ_p|`，**未捕获瞬态峰值**
4. **用户看图确认：所有参数俯仰均飙至 360°~数千度**，根因在于：
   - |Avg M_aero| ≈ 1800-2700 μN·m
   - M_gravity_max = ±2940 μN·m
   - 净力矩未归零 → θ_p 持续漂移, 短仿真 (1.5s) 看不出

## 4. v6.1 气动俯仰阻尼修复

### 4.1 修复原理

当身体以 θ̇_p 旋转时，翅膀处的线速度 = θ̇_p × x_wing：
- 前翅 (x>0): 等效攻角增加 → 升力变化
- 后翅 (x<0): 等效攻角减小 → 升力反向变化
- **前后翅力差异产生与 θ̇_p 反向的力矩 = 天然气动阻尼**

### 4.2 长时验证结果（t=10s, 200k steps）

| α_f | α_b | L/W | Peak θ_all | Peak θ_last80% | >90°? | Fz Q1-Q4 一致性 |
|-----|-----|-----|-----------|---------------|-------|-----------------|
| **60°** | **10°** | **1.145** | **45.7°** | 42.2° | **0** | +234/+215/+233/+215 |
| **55°** | **12°** | **0.962** | **40.9°** | 23.8° | **0** | +210/+174/+196/+174 |
| 50° | 15° | 0.711 | 34.3° | 21.0° | 0 | +157/+127/+148/+126 |
| 30° | 60° | 0.573 | 51.0° | 49.2° | 0 | +74/+119/+137/+119 |

### 4.3 重要发现

- **每步都检查**：`n_exceed_90 = np.sum(|θ_p| > 90°)` 遍历全部 200,000 个时间点
- **全部结果为 0** — 没有任何时刻超过 ±90°
- 四季度升力一致 → 系统达到稳态振荡，**无长期漂移**
- **α_f=60°/α_b=10° 首次实现 L/W > 1.0（L/W=1.145）**
- **α_f=55°/α_b=12° 接近悬停（L/W=0.962）**

### 4.4 公式使用问题

**100% 时间在平板失速区**。以 α_f=60°, θ_p≈20° 为例：

| 阶段 | α_eff 范围 | α_eff 均值 | 纯经验 | 过渡 | 纯平板 |
|------|-----------|-----------|--------|------|--------|
| 下拍 | +58°~+102° | +78° | 0% | 28% | 72% |
| 上拍 | −58°~−102° | −78° | 0% | 31% | 69% |

**经验公式（基于 LEV，|α|≤60°）完全未使用。** 翅膀像桨叶推空气，升力来自 D 的投影分量：Fz = cos(ψ) × (L + D) ≈ cos(20°) × 2.0·const。这不是蝴蝶真实飞行机制。

## 5. v6.2 低安装角扫描 — 回到 LEV 范围

### 5.1 目标与策略

- **目标**：让 α_eff 在经验公式有效范围内 (|α| ≤ 60°)
- **扫描**：α_f ∈ [28,30,32,35,38,40,42,45]°, α_b ∈ [10,15,18,20,22,25,28,30]° (64 组合)
- **验证**：t=3s, 每步检查 |θ_p|

### 5.2 全量结果

**64 组全部 n90=0，peak θ 均 < 36°。** 气动阻尼在经验公式范围同样有效。

### 5.4 规律总结

1. **最优模式明确**：α_f 大 (40-45°) + α_b 小 (10-15°)
2. **物理原因**：前翅大安装角 → 主导升力产生；后翅小安装角 → 主导向前推力
3. **L/W 随 α_f 单调递增**、**随 α_b 单调递减**
4. **α_max 在极端时刻仍可达 90-99°**，但这是拍动极端（φ≈±22°），发生在 U≈0 附近，力贡献很小
5. **中线攻角 (φ≈0 时)** α_eff ≈ α_install + θ_p ≈ 45° + 20° = 65°（稍超 60° 边界但过渡平滑）
