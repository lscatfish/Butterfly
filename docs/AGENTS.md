# Butterfly Aerodynamic Analysis — Agent Notes

## Project Overview
仿生蝴蝶（机械原理课程作业）翅膀气动参数提取与准定常力分解。
- 总质量 25 g，四翅总质量 4 g
- 扑动频率 15–20 Hz（典型值 17.5 Hz），下拍 80° 上拍 60°
- **运动学由前置连杆机构（mechanism.py）生成**
- 需分别计算前翅、后翅的升力/阻力/旋转力/附加质量力

## Critical Pitfall: DXF Export Only
- **绝对不要用 VBA `GetSketchSegments`**：返回的是全局坐标，且包含 20 m 长的参考构造线，导致数据完全错乱。
- **正确做法**：在 SolidWorks 中激活目标草图 → 文件 → 另存为 → DXF (R2000+) → 选项 → 仅输出激活草图 → 保存。
- 这样得到的 DXF 使用**草图局部坐标**（mm 量级，而非全局坐标 10,000 mm 量级）。

## DXF Parsing
- 使用自定义轻量级 parser（不依赖 ezdxf），解析 SPLINE / LINE / CIRCLE。
- SPLINE 用 scipy.interpolate.BSpline 采样为密集点（默认 2000 点）。
- 多个 SPLINE/LINE 段通过 nearest-neighbor 首尾相连（tolerance 0.1 mm）。
- **注意**：2026-05-29 修复了 parser 在遇到 code 0 时未终止当前实体块的 bug，避免 knots 数组被后续实体数据污染。

## Coordinate System
- 转轴由 `WingsAxis.DXF` 中两个圆的圆心定义：`p0` 和 `p1`。
- `unit_dir = (p1-p0)/|p1-p0|`：沿转轴方向（展向近似）。
- `unit_perp = (-unit_dir[1], unit_dir[0])`：垂直于转轴方向（弦向近似）。
- 局部坐标：
  - `r = (pts - p0) @ unit_dir`：沿转轴投影（弦向坐标）
  - `y = (pts - p0) @ unit_perp`：垂直转轴投影（展向坐标）
- 展长 `R = y_max - y_min`，面积通过沿展向分条积分弦长得到。

## Aerodynamic Model
基于文献综述的准定常分解（Dickinson 2001 / Sane & Dickinson 2002）。

### 1. 运动学参数
- **由前置连杆机构（mechanism.py）生成**：曲柄摇杆机构，主点绕 (x-a)²+(y-b)²=R² 转动，曲柄一周=翅膀一拍
- 典型频率 `f = 17.5 Hz`（范围 15–20 Hz）
- 下拍幅度 `φ_down = 80°`（向下），上拍幅度 `φ_up = 60°`（向上）
- 机构主点半径 R 控制运动波形（默认 2.25）
- 角速度和角加速度由机构几何直接微分得到

### 2. 气动力系数
- 升力系数：`C_L(α) = 0.255 + 1.58·sin(2.13·α - 7.2°)`，峰值 ~1.83 @ α≈45°
- 阻力系数：`C_D(α) = 1.92 - 1.55·cos(2.04·α - 9.82°)`，峰值 ~3.47 @ α≈90°
- ~~旋转力系数：`C_rot = 1.5`~~（固定攻角，旋转力=0）

### 3. 力分解公式
| 分量 | 峰值公式 | 时均估算 |
|------|---------|---------|
| 平动升力 | `0.5·ρ·C_L·(φ̇·R)²·S·r̂₂²` | 峰值 / 2（cos² 平均） |
| 平动阻力 | `0.5·ρ·C_D·(φ̇·R)²·S·r̂₂²` | 峰值 / 2 |
| ~~旋转力~~ | ~~`ρ·C_rot·α̇·φ̇·c_avg²·R²·r̂₁`~~ | ~~峰值 × 2·flip_ratio~~ |
| 附加质量力 | `-(ρ·π·c_avg²/4)·φ̈·R·r̂₁·sin(α)` | ≈0（周期对称） |

> **重要假设**：
> 1. 翅膀根部到转轴有约 9 mm 间距，但力公式中仍使用 `R = y_max - y_min` 作为有效展长（简化处理，误差约 10–20%）。
> 2. 运动学由前置连杆机构（mechanism.py）生成，曲柄一周=翅膀一拍。
> 3. **固定攻角假设**：机械蝴蝶的翅膀通过刚性结构安装，安装角度固定为 `α = +45°`，扑动过程中**无法主动翻转攻角**。这与真实昆虫的主动扭转机制不同。
> 4. **上拍升力方向反转**：由于攻角固定，平动升力方向由 φ̇ 符号决定。φ̇ ≤ 0（向下）→ 攻角 +α → C_L > 0；φ̇ > 0（向上）→ 攻角 -α → C_L < 0。
> 5. **旋转力消失**：固定攻角意味着 `α̇ = 0`，旋转力项为零。
> 6. 附加质量力：`F_AM = -(ρπc²/4)·φ̈·R·r̂₁·sin(α)`，阻力加速度方向。峰值出现在 stroke reversal（|φ̈|最大），时均≈0（对称抵消）。
> 7. 实际飞行中三维效应、涡脱落、柔性变形会使真实力显著低于准定常估算（可能低 30–50%）。

### 4. 力计算结果（机构运动学，2026-05-29）

**静态估算**（`analyze_dxf.py`）：
| 项目 | 四翅总计 |
|------|---------|
| 重量 | 245.25 mN |
| 峰值力 | 34,491 mN（= max(trans, |AM|)） |
| 时均升力 | 5,001 mN |
| 时均阻力 | 4,645 mN |
| 升重比 | 20.4 |

**动态分析**（`dynamic_analysis.py`，机构运动学）：
| 项目 | 四翅总计 |
|------|---------|
| 重量 | 245.25 mN |
| 峰值升力 | 42,496 mN |
| 时均升力 | 20,583 mN |
| 时均阻力 | 4,160 mN |
| 升重比 | 83.9 |

> **为什么静态估算（5,001 mN）远低于动态分析（20,583 mN）？**
> - 静态估算只做简化 `峰值/2`，假设半个周期为正升力、半个周期为零；
> - 动态分析完整积分：下拍产生强正升力，上拍产生负升力（向下），但下拍幅度更大（80° vs 60°），净结果仍为正；
> - 静态估算未反映上拍负升力的抵消效应，也未计入附加质量力的时均贡献（周期对称，≈0）。
>
> **注意**：固定攻角模型的时均升力仍远高于重量，原因包括：
> 1. 下拍幅度（80°）大于上拍（60°），下拍产生正升力的时间/幅度占优；
> 2. 准定常模型未计入三维效应和涡脱落造成的升力损失。
>
> 升重比远高于 1，说明在理论模型下升力极为充裕。实际中真实升重比会显著降低。对于机械原理作业，可作为设计裕度的理论上限参考。

## Dynamic Analysis (`dynamic_analysis.py`)
新增功能（2026-05-29）：
1. **机构运动学**：由 `mechanism.py` 生成 φ(t)。曲柄摇杆机构参数 R 控制波形。
2. **固定攻角模型**：刚性安装，攻角 +45° 不变，α̇=0，旋转力=0。
3. **C_L 基于瞬时速度方向**：φ̇ ≤ 0 → C_L(+α)；φ̇ > 0 → C_L(-α)。
4. **F_AM = -(ρπc²/4)·φ̈·R·r̂₁·sin(α)**：阻力加速度。
5. **参数扫描**：频率 10-25 Hz、幅度 40-100°、攻角 20-70°。
6. **图表**：`force_vs_phi.png`、`force_time_domain.png`、`wing_acceleration.png`、`param_scan.png`。
7. **Markdown 报告**：`气动分析报告.md`。

### 转角约定
- 机构运动学：曲柄一周 = 翅膀一拍，φ=0 居中
- `φ < 0`：下拍（翅膀向下运动）
- `φ > 0`：上拍（翅膀向上运动）
- 固定攻角 α = +45°，无翻转
