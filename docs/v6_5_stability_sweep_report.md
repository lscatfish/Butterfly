# v6.5 单变量偏离稳定性扫描 — 完整实验报告

**日期**: 2026-06-06 | **版本**: v6.5 | **模型**: butterfly_forces.py (v6.3 LEV/Lee C_L/C_D)

---

## 摘要

基于基线配置（α_f=68°, α_b=5°, phase=-15°, a=6.0 mm, R=2.5 mm, φ_offset=-50.84°），对6个关键参数进行单变量偏离扫描，每个参数独立变化而其余参数保持基线值。共计48个仿真点，每点仿真5.0 s物理时间（dt=50 μs, 100,000 RK4步长）。所有结果均基于体轴系和世界系双坐标系输出，其中L/W指标以世界系Fz_world为物理悬停判据。

**核心发现：**
1. 机构曲柄半径 `mech_a` 是最敏感参数——a=5.0 mm 时 L/W=8.246（基线3.3倍）
2. 摇杆安装角 `φ_offset` 存在显著单调趋势——从-65°增至-30°，L/W从1.21单调升至3.73
3. 曲柄半径 `mech_R` 存在稳定性临界上限——R=3.5 mm 时发散（peak θ=25982°）
4. 相位差 `phase` 为尖锐最优——偏离±5°即导致L/W下降~10%
5. 前后翅安装角 `α_f` 和 `α_b` 在基线附近极为平坦——几乎不影响性能

## 1. 引言

### 1.1 背景

仿生蝴蝶扑翼MAV的俯仰动力学仿真已发展至v6.3版本，采用刚性翅膀+非对称安装角+LEV/Lee混合C_L/C_D模型+4分量力模型（平动力F_trans、附加质量力F_AM、旋转力F_rot、Clap-and-Fling力F_clap）。v6.4通过逐参数轮转优化获得L/W_world=10.44的最优配置。本实验（v6.5）旨在系统量化每个参数独立偏离基线时对升力、稳定性、力矩和运动学的影响，为后续全参数笛卡尔积扫描（方案二）和水平运动扩展提供数据基础。

### 1.2 评估指标

| 指标 | 符号 | 定义 |
|------|------|------|
| 升重比（世界系） | L/W | mean(Fz_world[t>T/2]) / (m·g)，物理悬停判据 |
| 俯仰角峰值 | peak θ_p | max(|θ_p(t)|)，稳定性关键指标（>90°为发散） |
| 超90°步数 | n90 | 全程|θ_p|>90°的步数，>0表示触地 |
| 体轴系垂向力均值 | mean Fz_body | 翅膀-身体界面法向力 |
| 世界系垂向力均值 | mean Fz_world | 对抗重力的真实升力 |
| 体轴系推力均值 | mean Fx_body | 体轴前向力 |
| 气动俯仰力矩均值/峰值 | M_aero | 前后翅Fz差产生的俯仰力矩 |
| 重力恢复力矩均值 | M_grav | -m·g·d_cg·sin(θ_p) |
| 阻尼力矩峰值 | M_damp | -c_damp·θ̇_p |
| 俯仰角速度 | \|θ̇_p\| mean/peak | 俯仰振荡剧烈程度 |
| 俯仰角加速度 | \|θ̈_p\| mean/peak | 俯仰力矩不平衡程度 |

## 2. 方法

### 2.1 基线配置

```
α_front = 68°        α_back = 5°         phase_diff = -15°
mech_a = 6.0 mm       mech_R = 2.5 mm     φ_offset = -50.84°
f = 15 Hz             m = 20 g            I_yy = 3×10⁻⁵ kg·m²
d_cg = 15 mm          x_front = +25 mm    x_back = -25 mm
dt = 50 μs            t_end = 5.0 s       steady_start = 3.0 s
ρ = 1.225 kg/m³       k_3d = 0.7          C_rot = 1.5 (未激活)
k_clap = 1.3          c_damp = 5×10⁻⁴
```

**基线性能**：L/W=2.505, peak θ_p=58.1°, n90=0, Fz_world=+460 mN（>196 mN重量）

### 2.2 扫描参数

所有6参数使用 v6.4 优化中确定的合理范围：

| 参数 | 扫描值 | 物理意义 |
|------|--------|----------|
| α_front | 40, 45, 50, 55, 60, 65, 68, 70 | 前翅安装角 (°) |
| α_back | 3, 5, 8, 10, 12, 15, 18 | 后翅安装角 (°) |
| phase_diff | -45, -30, -20, -15, -10, -5, 0, 5, 10 | 前后翅相位差 (°) |
| mech_a | 5.0, 6.0, 7.0, 7.5, 7.92, 8.5, 9.5, 11.0, 12.0 | 曲柄铰链A的y坐标 (mm) |
| mech_R | 2.0, 2.25, 2.5, 2.75, 3.0, 3.5 | 曲柄半径 (mm) |
| phi_offset | -65, -60, -55, -50.84, -48, -45, -40, -35, -30 | 翅膀在摇杆上的安装偏角 (°) |

### 2.3 实验流程

1. 从基线配置出发，仅改动目标参数
2. ButterFlyForceModel → 运动学预计算 → RK4俯仰ODE积分 → 向量化力批处理
3. 每点保存 config.json + summary.json + timeseries.npz（~34 MB/点）
4. 扫描完成后通过 stability_plot.py 独立出图（41张）
5. 全部结果存入 `temp/stability/sweep_<param>/`

- 结论：相位 -15°±5° 是关键设计窗口，需要精确制造

### 3.5 mech_a — 曲柄铰链A的y坐标（5.0-12.0 mm）

**图组**：`temp/stability/figures/sweep_mech_a/` (6张)

| a | L/W | peak θ_p | Fz_world | n90 | 摆幅估算 |
|---|-----|----------|----------|-----|----------|
| **5.0** | **8.246** | 39.3° | +1585 mN | 0 | 大摆幅 |
| 6.0 | 2.505 | 58.1° | +460 mN | 0 | 基线 |
| 7.0 | 1.066 | 65.0° | +187 mN | 0 | 不足重量 |
| 7.5 | 0.669 | 68.5° | +115 mN | 0 | 明显不足 |
| 7.92 | 0.474 | 68.8° | +79 mN | 0 | 原始设计 |
| 8.5 | 0.319 | 73.0° | +52 mN | 0 | 严重不足 |
| 9.5 | 0.213 | 80.8° | +34 mN | 0 | 临界 |
| 11.0 | 0.191 | 89.3° | +34 mN | 0 | 极度临界 |
| 12.0 | 0.207 | 95.8° | +38 mN | 71425 | **发散** |

**发现（本次扫描最显著）：**
- a=5.0 mm 时 L/W=8.246 → Fz_world=+1585 mN，是重量的 8.08 倍，**远超悬停需求**
- a 减小时机构拍动角幅值增大 → 有效速度 U 增大 → 升力按∝U²急剧增长
- a>7.0 mm 时 L/W<1.0 → 不能悬停
- a≥12.0 mm 时发散（n90=71425）→ 机构提供的拍动力矩不足以抵消气动俯仰力矩
- \|θ̇_p\| mean 在 a=5.0 时最大（5.63 rad/s）→ 高升力伴随高振荡频率
- 但 peak θ_p 在 a=5.0 时仅 39.3° → 尽管振荡频率高，幅值反而更小
- **结论：a 是决定性的设计参数，越小越好，但受机构几何约束（a_min 由曲柄-摇杆可装配性决定）**

## 4. 讨论

### 4.1 参数敏感度排序

| 参数 | 敏感度 | L/W 范围 | 变异系数 | 趋势 |
|------|--------|----------|----------|------|
| **mech_a** | ⭐⭐⭐⭐⭐ | 0.19→8.25 | 2.07 | 单调↓ |
| **mech_R** | ⭐⭐⭐⭐ | 1.21→6.73 (稳定) | 0.75 | 单调↑ (有临界) |
| **phi_offset** | ⭐⭐⭐ | 1.21→3.73 | 0.37 | 单调→0 |
| **phase_diff** | ⭐⭐⭐ | 1.77→2.51 | 0.14 | 尖锐最优 |
| α_back | ⭐ | 2.33→2.51 | 0.03 | 平坦 |
| α_front | ⭐ | 2.30→2.51 | 0.03 | 极平坦 |

### 4.2 单调 vs 最优型参数

- **单调型** (mech_a, mech_R, phi_offset)：没有内部最优值，性能在可行域边界上最优化 → 优化受机械约束限制
- **最优型** (phase_diff)：存在尖锐内部最优点 → 精确制造和装调关键
- **平坦型** (α_f, α_b)：在宽范围内性能几乎不变 → 设计鲁棒性高

### 4.3 与 v6.4 优化结果的印证

v6.4 通过逐参数轮转优化（coordinate ascent）发现的最优趋势与本次单变量扫描完全一致：
- a=5.0 最优（本次确认 L/W=8.246）
- R 增大有利但有上限（本次发现 R_crit ∈ (3.0, 3.5) mm）
- φ_offset= -30° 最优（本次确认 L/W=3.728）
- phase=-15° to -30° 最优区（phase=-15° 在基线 R=2.5 时最优，与 v6.4 发现的 a×phase 耦合一致）

### 4.4 稳定性裕度

所有非发散的扫描点中，peak θ_p 范围为 39.3°（a=5.0）至 89.3°（a=11.0），全在 90° 以下 → 当前参数范围内的稳定设计空间充足。但 R=3.5 和 a=12.0 两点触及发散，表明参数空间中存在陡峭的稳定性峭壁。

---

## 5. 结论

1. **机构参数主导性能**：mech_a 和 mech_R 是最关键的优化参数，其影响远超气动参数（α_f, α_b）
2. **摇杆安装角φ_offset被低估**：之前从未系统性扫描，发现±35°的变化可使L/W变化3倍
3. **α_f/α_b的鲁棒性是好消息**：制造误差在安装角上不会显著影响飞行性能
4. **相位差需精确控制**：-15°±5°的最佳窗口很窄
5. **存在稳定性临界R**：R≈3.0 mm 在性能/稳定性平衡上最佳
