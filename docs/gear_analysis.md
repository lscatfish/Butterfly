# 定轴轮系分析模块（gear_analysis.py）

> 本文件说明 `src/gear_analysis.py` 的功能、数据结构与输出。  
> 用于分析仿生蝴蝶减速器的两级定轴外啮合圆柱齿轮传动。

---

## 1. 功能概述

分析两级定轴圆柱齿轮减速器的几何参数、啮合特性和传动效率：

- **齿轮几何**：分度圆、基圆、齿顶圆、齿根圆、齿厚、齿顶高、齿根高
- **啮合特性**：标准中心距、实际中心距、啮合角、端面重合度
- **传动比**：总传动比、单级传动比（外啮合为负）
- **效率估算**：齿轮啮合效率 + 轴承效率

---

## 2. 轮系结构

```
轴I  —— 齿轮1  (z1=7,   正变位 x1)
        ↕ 外啮合
轴II —— 齿轮2  (z2=40,  负变位 x2) + 齿轮2' (z2'=7, 正变位 x2') [双联固连]
        ↕ 外啮合
轴III—— 齿轮3  (z3=40,  负变位 x3)
```

- 设计为**等变位传动**：x1+x2=0, x2'+x3=0
- 模数 m = 0.3 mm，压力角 α = 20°
- 总减速比 |i13| = (40/7)² ≈ **32.65**

---

## 3. 核心类

### 3.1 `GearSpec`

单个渐开线圆柱齿轮的几何参数数据类。

| 字段 | 说明 |
|---|---|
| `label` | 齿轮编号 |
| `z` | 齿数 |
| `x` | 变位系数 |
| `m` | 模数 [mm] |
| `alpha` | 压力角 [rad] |
| `d` | 分度圆直径 |
| `db` | 基圆直径 |
| `da` | 齿顶圆直径 |
| `df` | 齿根圆直径 |
| `ha` / `hf` / `h` | 齿顶高 / 齿根高 / 全齿高 |
| `p` | 齿距 |
| `s` | 分度圆齿厚 |
| `pb` | 基圆齿距 |
| `alpha_a` | 齿顶圆压力角 [rad] |

### 3.2 `MeshPair`

一对啮合齿轮的参数。

| 字段 | 说明 |
|---|---|
| `a_std` | 标准中心距 |
| `a_actual` | 实际中心距（等变位时 a'=a）|
| `alpha_prime` | 啮合角 [rad] |
| `u` | 齿数比 |
| `eps_alpha` | 端面重合度 |
| `i_ratio` | 传动比（外啮合为负）|

### 3.3 `FixedAxisGearTrain`

两级减速器分析器。

**关键属性**：
- `z_min` — 不根切最小齿数
- `x1`, `x2`, `x2p`, `x3` — 等变位系数（自动计算）
- `i_total` — 总传动比
- `eta_total` — 总效率（齿轮² × 轴承³）

---

## 4. 使用示例

```python
from gear_analysis import FixedAxisGearTrain

train = FixedAxisGearTrain(
    teeth=(7, 40, 7, 40),
    module=0.3,
    alpha_deg=20.0,
)
train.print_summary()
```
