- |θ_p| > 60° = 边界不稳定（不可接受）
- |θ_p| < 30° = 稳定（目标范围）

## 4. 关键发现与分析

### 4.1 🔴 核心发现：高升力伴随高俯仰

能够产生正升力且接近或超过重量（L/W > 0.4）的参数组合（如 α_f=20°/α_b=60°、α_f=30°/α_b=60°）在**同相**模式下表现良好，但俯仰角达到 46-57°，超过稳定阈值 30°。

**物理原因**：后翅大安装角 (60°) 产生巨大下拍升力，但前翅小安装角 (20°) 产生的前向力不足以平衡俯仰力矩 → 蝴蝶持续抬头。

### 4.2 🟡 最佳稳定组合：α_f=60°/α_b=10°

**唯一同时满足两者稳定且同相正升力的参数**：
- 同相 fixed: L/W=0.471, |Pitch|=22.0°
- 反相 fixed: L/W≈0, |Pitch|=10.4°
- 同相 moving: L/W=0.407, |Pitch|=22.0°, Vx_max=4.9 m/s

**物理图像**：前翅大安装角 (60°) → 前翅产生大部分升力，力臂靠前；后翅小安装角 (10°) → 后翅主要提供推力而非升力。前翅主导升力 + 后翅辅助推力 = 较好的俯仰平衡。

### 4.3 🟢 对称安装角几乎全是负升力

α_f=α_b 的所有组合净升力为负（L/W < 0），最接近零的是 60°/60° 的 L/W=-0.499。这证明了**不对称安装角**的必要性。

### 4.4 🔵 移动模型的影响

引入 Vx 自由度后：
- 升力普遍降低（部分力转为前飞加速）
- 俯仰稳定性略有改善
- Vx 加速可达 20-35 m/s（对高 α_b 组合），但对应的俯仰也很高
- 对稳定组合（α_f=60°/α_b=10°），Vx ≈ 5 m/s，这是合理的前飞速度

### 4.5 ⚫ 反相模式的问题

反相 180° 下所有组合均表现不佳：
- 正升力的组合俯仰 > 60°（不稳定）
- 稳定的组合升力 ≤ 0
- **最大推力**反而出现在反相模式（+308 mN at α_f=20°/α_b=60°）

**反相不适用当前机构**。后翅反相时运动与同相相反，前后翅的升力峰值错开，导致俯仰力矩剧烈振荡。

## 6. 模型局限性（已知问题）

1. **高攻角公式**：|α_eff| 在拍动极端可超过 70°，此时混合模型转用平板公式，精度有限
2. **前飞效应简化**：当前忽略 Vx 对相对来流方向的修正。Vx > 5 m/s 时应升级为向量合成
3. **Blade-element**：当前用全局面积矩 (r₁, r₂²)，未用 chord_distribution.csv 沿展向积分
4. **α_dot = 0**：机构无扭转自由度，F_rot ≡ 0。若引入被动扭转需重新激活旋转力
5. **仅俯仰+前飞**：未包含垂直运动 (z) 和滚转 (roll)
