### 1.3 参数规律

```
α_f ↑ → 前翅升力 ↑ → L/W ↑（主驱动）

最优模式：α_f 大 (40-45°) + α_b 小 (10-15°)
```

## 2. 模型架构

### 2.1 物理核心

```
攻角: α_eff = ±(α_install + φ + θ_p + Δα_damp)
气动俯仰阻尼: Δα = atan(θ̇_p × x_wing / U)
力投影: Fz=cos(ψ)(L−sign·D), Fx=sin(ψ)(sign·D−L)
C_L/C_D: LEV 经验(0-40°) → smoothstep 过渡(40-70°) → 平板失速(>70°)
俯仰: I_yy·θ̈ = M_aero + M_gravity + M_damp + M_aero_damp
```

### 2.2 关键常数

| 参数 | 值 | 物理角色 |
|------|-----|---------|
| m_total | 20g | 重量 196.2 mN |
| I_yy | 3e-5 | 俯仰惯量 |
| M_grav_max | ±2943 μN·m | 最大重力恢复 |
| c_damp | 5e-4 | 粘性阻尼 |
| k_3d | 0.7 | 三维修正 |
| φ range | ±22.2° | 机构拍动范围 |

## 3. 历史问题回顾

### 3.1 v4 双重投影（废弃）

v4 中 `Fx = sin(ψ)(sign·D - L)` 和 `R_y(ψ) @ [Fx_wing, 0, Fz_wing]` 同时使用，等价于对力旋转两次，完全错误。

### 3.2 v5 常量攻角假设（废弃）

v5 将 α_down、α_up 作为两个独立常数扫描。这隐含地假设翅膀有**主动扭转**机构——上拍时主动将攻角从几何决定的 -60° 扭转到 -5°。v6 的刚性模型揭示了这个假设的不合理性。

### 3.3 v6 俯仰发散（最严重问题）

**根因**：M_aero 时间均值 1800-2700 μN·m，而 M_gravity_max = ±2940 μN·m。净力矩约 450-1400 μN·m 未被平衡，在 1.5s 仿真中不明显，但在 3s+ 时俯仰飙至数千度。

**为什么 1.5s 仿真看不出**：θ̇_p 漂移速率约 0.03-0.15 rad/s，1.5s 仅累积 3-13°。但持续累积，10s 后就是 17-86°，100s 后完全发散。

**教训**：必须检查每步瞬时 |θ_p|，不能只看稳态窗口内的 max。

### 3.4 v6.1 高 α 公式问题

α_install=60° + θ_p≈20° → α_geom = 80°。拍动极端 φ=±22° 再加 → α_eff ∈ [58°, 102°]。100% 时间在平板失速区，经验公式未被使用。虽然 L/W=1.145 看起来很好，但力来自阻力投影（桨叶效应）而非 LEV 涡升力。

## 4. 稳定性判据

```
✅ 稳定：全时程每步 |θ_p| < 90°（n90=0）
⚠️  边际：n90≤10 或 peak<180°
❌ 发散：n90>10 或 peak>180°
```

**v6.2 全部 64 组 n90=0。** 所有组合在全 3s 仿真中没有任何一步超过 ±90°。

## 5. 未来改进方向

### 5.1 短期（高优先级）

| 方向 | 做法 | 预期提升 |
|------|------|---------|
| **精细扫描** | α_f ∈ [43,48]°, α_b ∈ [8,14]°, 步长 1° | 找 L/W 更大的 LEV 范围解 |
| **启用前飞 Vx** | v6.2 目前仅 fixed 模型；前飞时来流不对称可能自然提升 L/W | L/W +0.1~0.2 |
| **v6.2 10s 验证** | 确认低 α 组合在长时仿真无累积漂移 | 可靠性确认 |

### 5.2 中期（中等优先级）

| 方向 | 做法 | 说明 |
|------|------|------|
| **Blade-element** | 用 `chord_distribution.csv` 沿展向 200 段积分 | 替代全局 r₁/r₂² 近似 |
| **前飞修正** | `v_rel = v_flap + v_body` 向量合成 | 当前简化忽略 Vx 对来流方向修正 |
| **相位扫描** | 测试 π/4, π/2, 3π/4 | 可能找到更好的前后翅配合 |

### 5.3 长期（未来方向）

| 方向 | 做法 | 说明 |
|------|------|------|
| **被动扭转** | 铰链弹性 → α 随气动载荷变化 | 上拍时自动减小 |α| → 减少负升力 |
| **频率优化** | 扫 f ∈ [18, 25] Hz | U² ∝ f² → 升力可能翻倍 |
| **机构参数优化** | 扫 a (改变摆幅和急回比) | 改变上/下拍时间分配 |
| **多自由度** | 添加 z (垂直) + roll | 完整飞行仿真 |
