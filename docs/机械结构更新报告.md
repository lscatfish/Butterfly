### 2.3 Grashof 条件验证

Grashof 条件：最短杆 + 最长杆 ≤ 中间两杆之和

| 杆件 | 长度 (mm) |
|------|-----------|
| 曲柄 R | 3.8（最短杆） |
| 连杆 c | 7.1 |
| 摇杆 l | 5.0 |
| 机架 AB | 7.79（最长杆） |

- 最短 + 最长 = 3.8 + 7.79 = **11.59 mm**
- 中间两杆和 = 7.1 + 5.0 = **12.10 mm**
- **11.59 ≤ 12.10 → Grashof 条件满足 ✅**

曲柄可整周回转，机构无死点。

## 六、仿真结论变化

### 6.1 旧结论（v6.8）

| 指标 | 旧值 |
|------|------|
| L/W (world) | 2.447 |
| L/W (body) | 2.45 |
| peak θ | 32.9° |
| Fz_world | +469 mN |
| mean \|α_eff\| | 45.9° |
| n_exceed_90 | 0 |

### 6.2 新结论（基线 α_f=60°, α_b=3°, phase=-15°）

| 指标 | 新值 | 变化 |
|------|------|------|
| L/W (world) | **4.563** | **+86%** |
| L/W (body) | **5.504** | +125% |
| peak θ | **59.3°** | +80% |
| Fz_world | **+895 mN** | +91% |
| Fz_body | +1080 mN | — |
| n_exceed_90 | 0 | 不变（仍稳定） |

### 6.3 关键发现

1. **升力大幅提升**：L/W 从 2.45 提升至 4.56（+86%），主要得益于新机构摆幅增大（99° vs 44°）带来的气动力增长。

2. **俯仰角增大但仍稳定**：peak θ 从 32.9° 增至 59.3°，未超过 90° 阈值，系统仍稳定。

3. **参数容差更宽**：旧机构 DESIGN_v68 容差极窄（mech_a=6 和 mech_R=2.5 是唯一稳定值）；新机构在 α_f=50-70°、α_b=3-8°、phase=-15°~-10°、k_clap=0.3-1.5 范围内均稳定。

4. **最优相位差变化**：从 -20° 变为 -15°，说明新机构运动学特性不同，需要不同的前后翅相位配合才能稳定。

5. **最优安装角变化**：前翅从 45° 增至 60°，后翅从 8° 降至 3°，配合更大的摆幅实现更高升力。
