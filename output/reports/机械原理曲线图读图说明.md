# 机械原理曲线图读图说明

本文档专门说明机械原理分析中几张简图和曲线图的读法。重点不是重新推公式，而是把曲线横坐标 `0°~360°` 与曲柄摇杆机构的实际运动阶段对应起来。

---

## 一、先看机构对应关系

实际机构可抽象为平面曲柄摇杆机构：

![实际机构简图](../figures/mechanism_schematic_reference.png)

![曲柄摇杆机构参考图](../figures/crank_rocker_reference.png)

在本分析中：

| 点 | 含义 |
|:---|:---|
| B | 曲柄固定转轴，也是齿轮输出轴位置 |
| P1 | 曲柄端点，随曲柄绕 B 点转动 |
| P2 | 连杆与摇杆的连接点 |
| A | 摇杆固定铰，也是翅膀绕转的等效枢轴 |

曲柄转角记为 `θ`，横坐标 `0°~360°` 表示曲柄转过一整圈。摇杆/翅膀摆角记为 `φ`。当前计算结果中：

```text
θ ≈ 83.5°  ：φ 最小，约 15.18°，小摆角端换向
θ ≈ 238.5° ：φ 最大，约 70.98°，大摆角端换向
```

因此一圈运动可以粗分为：

```text
83.5° → 238.5°      ：φ 增大，摇杆从小摆角端摆到大摆角端
238.5° → 360° → 83.5°：φ 减小，摇杆从大摆角端摆回小摆角端
```

如果在实际样机说明中把这两段分别叫作上拍、下拍，名称可以按你的定义调整；但曲线判断时最可靠的是看 `φ` 是增大还是减小。

---

## 二、曲柄摇杆受力简图怎么看

![曲柄摇杆受力简图](../figures/crank_rocker_fbd_reference.png)

这张图用于说明力从翅膀侧传回电机侧的路径：

```text
翅膀外载力矩 M
→ 摇杆 3
→ 连杆 2
→ 曲柄 1
→ 驱动力矩 Md
```

下面三个拆构件图中的红圈是摩擦圆。考虑转动副摩擦时，铰链反力的作用线不再穿过销轴中心，而是与摩擦圆相切。当前数值计算没有逐个铰链列摩擦圆平衡，而是采用简化处理：把曲柄摇杆转动副摩擦、摩擦圆和装配损失压缩为一个等效效率 `η_l=0.90`。

所以报告中的力矩链为：

```text
P = M_wing · φ_dot
T_crank = P / (ω_crank · η_l)
T_motor = T_crank / (i13 · η_g)
```

其中 `η_g=0.9319` 是轮系效率，`η_l=0.90` 是曲柄摇杆等效效率。

当前曲线图已经对 `M_aero` 做了周期 Hann 窗平滑处理。这样处理的目的，是把气动分段公式造成的小尖角近似为真实流场中的连续过渡；四杆机构换向和高加速度造成的大趋势仍然保留。

## 三、关键角度与实际运动阶段

| 曲柄角范围 | 机构状态 | 摇杆运动 | 读图重点 |
|:---|:---|:---|:---|
| `0°~83.5°` | 接近小摆角端 | `φ` 减小，速度逐渐降到 0 | 机构在制动摇杆，准备换向 |
| `83.5°` | 小摆角端换向 | `φ_dot≈0` | 力矩可能明显，但功率不一定大 |
| `83.5°~148°` | 从小摆角端离开 | `φ` 增大，正向加速 | 惯性力矩上升，机构把翅膀甩起来 |
| `148°~188°` | 向大摆角端快速摆动 | `φ_dot` 继续增大 | 摇杆速度高，功率开始变大 |
| `188°~238.5°` | 接近大摆角端 | `φ` 仍增大，但开始减速 | 负角加速度很大，出现制动峰 |
| `238.5°` | 大摆角端换向 | `φ_dot≈0` | 惯性项强，但功率被速度项压低 |
| `238.5°~261.5°` | 从大摆角端刚返回 | `φ` 减小 | 外载力矩绝对值最大 |
| `261.5°~272.5°` | 返回过程中的高负载区 | `φ` 减小且速度较大 | 曲柄轴、电机轴和齿轮力达到峰值 |
| `272.5°~308.5°` | 返回中段 | `φ_dot` 负向速度较大 | 速度高，但外载下降，扭矩回落 |
| `308.5°~360°` | 返回后半段 | `φ` 继续减小 | 逐步进入下一圈小摆角端换向 |

## 四、摇杆端等效外载力矩图

![摇杆端等效外载力矩](../figures/rocker_moment_vs_crank_angle.png)

这张图画的是作用在摇杆端的等效外载力矩：

```text
M_wing = M_aero + M_inertial
M_inertial = I_w · φ_ddot
```

### 0°~83.5°

摇杆正在向小摆角端运动，`φ` 从约 `30.5°` 减小到 `15.2°`。此时 `φ_dot<0`，但逐渐接近 0，说明摇杆正在被机构减速。图中惯性力矩偏正，对应实际运动就是翅膀快到端点，需要被机构制动并准备反向。

### 83.5°附近

这是小摆角端换向点。`φ_dot≈0`，所以摇杆端虽然仍有外载力矩，但它对应的瞬时功率不一定大。这里更应该看作“换向位置”，不是电机最大负载位置。

### 83.5°~188°

摇杆离开小摆角端，`φ` 增大。先是正向加速，然后速度逐渐升高。`148°` 附近角加速度达到正峰值，所以惯性力矩出现明显上升；`188°` 附近速度最大，对应翅膀通过中段的高速运动。

### 188°~238.5°

摇杆继续向大摆角端摆动，但开始减速。`225.5°` 附近角加速度达到负峰值，说明机构正在强烈制动摇杆，让它停在大摆角端。因此惯性力矩会向负方向急剧变化。

### 238.5°~261.5°

摇杆刚从大摆角端反向返回，气动项和惯性项在部分区间同向叠加。平滑后 `261.5°` 附近 `M_wing` 的绝对值达到最大：

```text
M_wing_peak ≈ 1375.26 N.mm
```

这个峰值对应的是“摇杆端外载最大”，不是“电机扭矩最大”。原因是电机扭矩还要看摇杆速度。

### 261.5°~360°

摇杆继续向小摆角端返回。外载力矩从大峰值逐渐回落。到 `308.5°` 附近，摇杆负向速度最大，但外载已经下降，所以摇杆端力矩图不再保持最大。

## 五、曲柄轴与电机轴扭矩图

![曲柄轴与电机轴扭矩](../figures/torque_chain_vs_crank_angle.png)

这张图不是直接画 `M_wing`，而是通过功率等效换算：

```text
P = M_wing · φ_dot
T_crank = P / (ω_crank · η_l)
T_motor = T_crank / (i13 · η_g)
```

所以读这张图时要同时看两个因素：

```text
M_wing 是否大
φ_dot 是否大
```

只有外载力矩大、摇杆速度也大时，曲柄轴扭矩才容易达到峰值。

### 0°~83.5°

摇杆向小摆角端返回，`φ_dot<0`。这段曲柄轴扭矩多为负，表示该瞬时载荷对曲柄转动有助推或回馈趋势。实际运动上，是翅膀接近端点并被制动，电机不处于最大正向驱动区。

### 83.5°~188°

摇杆从小摆角端离开，`φ_dot>0` 且逐渐增大。随着速度上升，曲柄轴扭矩也明显上升。`188°` 附近摇杆速度最大，曲柄轴扭矩处于较高水平。

### 188°~238.5°

摇杆接近大摆角端，开始强烈减速。此时 `M_wing` 可能转为负，而 `φ_dot` 仍为正，所以 `P=M_wing·φ_dot` 变为负，曲柄轴扭矩图出现负峰。`224.5°` 附近：

```text
T_crank ≈ -223.90 N.mm
```

这个负峰对应的是大摆角端前的制动区。

### 238.5°~261.5°

摇杆刚换向返回，外载力矩绝对值很大，但速度还在建立。曲柄扭矩开始由负转正并快速上升。

### 261.5°~272.5°

这是电机和曲柄最吃力的一段。此时 `M_wing<0`，`φ_dot<0`，二者相乘为正，而且二者绝对值都比较大。因此曲柄轴扭矩达到正峰：

```text
θ ≈ 272.5°
T_crank_peak ≈ 235.65 N.mm
T_motor_peak ≈ 7.744 N.mm
```

实际运动对应的是：翅膀从大摆角端返回后进入高负载、高速度区，电机需要输入最大正功率。

### 272.5°~360°

摇杆继续向小摆角端返回。虽然 `φ_dot` 在 `308.5°` 附近达到负向最大速度，但外载力矩已经下降，所以曲柄轴扭矩逐渐回落。实际运动就是通过高负载区后进入返回后半段。

## 六、齿轮啮合力图

![齿轮啮合力随曲柄转角变化](../figures/gear_mesh_forces_vs_crank_angle.png)

齿轮啮合力由扭矩换算：

```text
Ft = 2T / d
Fr = Ft · tanα
Fn = Ft / cosα
```

这张图画的是力的大小，所以和曲柄轴、电机轴扭矩的绝对值趋势基本一致，不保留正负号。

### 为什么第二级更大

第二级齿轮 2'-3 靠近输出轴，承担的是减速后的较大输出扭矩，所以第二级啮合力明显大于第一级。

当前峰值为：

| 啮合副 | Ft | Fr | Fn | 对应状态 |
|:---|---:|---:|---:|:---|
| 齿轮 1-2 | 7.376 N | 2.685 N | 7.849 N | 电机端输入齿轮处峰值 |
| 齿轮 2'-3 | 39.275 N | 14.295 N | 41.796 N | 输出级靠近曲柄轴，载荷最大 |

### 峰值为什么在 272.5° 附近

因为这一点也是曲柄轴和电机轴扭矩峰值点。实际运动状态是摇杆从大摆角端返回后进入高负载区，翅膀外载力矩和摇杆速度共同使输入功率最大。因此齿轮齿面接触力、轴承径向载荷也在这里达到最大。

---

## 七、读图时最容易混淆的点

1. `M_wing` 峰值不等于 `T_crank` 峰值。  
   `M_wing` 只看摇杆端外载；`T_crank` 看的是功率等效，即 `M_wing · φ_dot`。

2. 换向点不一定是电机最吃力点。  
   换向点附近 `φ_dot≈0`，即使力矩明显，功率也可能被速度项压低。

3. 齿轮啮合力图画的是力的大小。  
   所以它不会显示正负方向，而是跟扭矩绝对值走。

4. 最需要校核的区间是 `261.5°~272.5°`。  
   `261.5°` 附近摇杆端外载最大，`272.5°` 附近曲柄轴、电机轴和齿轮啮合力最大。

---

## 八、一句话读图

这三张线图可以按下面这条实际运动链理解：

```text
小摆角端换向 83.5°
→ 摇杆加速摆向大摆角端
→ 大摆角端前强制减速，出现负扭矩区
→ 大摆角端换向 238.5°
→ 返回初期外载最大 261.5°
→ 返回高负载高速区，电机和齿轮力最大 272.5°
→ 返回后半段载荷下降
→ 下一圈小摆角端换向
```
