# 机械原理曲线图读图说明

本文档专门说明机械原理分析中几张简图和曲线图的读法。重点不是重新推公式，而是把曲线横坐标 `0°~360°` 与曲柄摇杆机构的实际运动阶段对应起来。

---

## 一、先看机构对应关系

实际机构可抽象为平面曲柄摇杆机构：

![实际机构简图](../figures/mechanism_schematic_reference.png)

![曲柄摇杆机构参考图](../figures/crank_rocker_reference.png)

在本分析中：

| 点 | 含义 |
|:---|:---|
| B | 曲柄固定转轴，也是齿轮输出轴位置 |
| P1 | 曲柄端点，随曲柄绕 B 点转动 |
| P2 | 连杆与摇杆的连接点 |
| A | 摇杆固定铰，也是翅膀绕转的等效枢轴 |

曲柄转角记为 `θ`，横坐标 `0°~360°` 表示曲柄转过一整圈。摇杆/翅膀摆角记为 `φ`。当前计算结果中：

```text
θ ≈ 83.5°  ：φ 最小，约 15.18°，小摆角端换向
θ ≈ 238.5° ：φ 最大，约 70.98°，大摆角端换向
```

因此一圈运动可以粗分为：

```text
83.5° → 238.5°      ：φ 增大，摇杆从小摆角端摆到大摆角端
238.5° → 360° → 83.5°：φ 减小，摇杆从大摆角端摆回小摆角端
```

如果在实际样机说明中把这两段分别叫作上拍、下拍，名称可以按你的定义调整；但曲线判断时最可靠的是看 `φ` 是增大还是减小。

---

## 二、曲柄摇杆受力简图怎么看

![曲柄摇杆受力简图](../figures/crank_rocker_fbd_reference.png)

这张图用于说明力从翅膀侧传回电机侧的路径：

```text
翅膀外载力矩 M
→ 摇杆 3
→ 连杆 2
→ 曲柄 1
→ 驱动力矩 Md
```

下面三个拆构件图中的红圈是摩擦圆。考虑转动副摩擦时，铰链反力的作用线不再穿过销轴中心，而是与摩擦圆相切。当前数值计算没有逐个铰链列摩擦圆平衡，而是采用简化处理：把曲柄摇杆转动副摩擦、摩擦圆和装配损失压缩为一个等效效率 `η_l=0.90`。

所以报告中的力矩链为：

```text
P = M_wing · φ_dot
T_crank = P / (ω_crank · η_l)
T_motor = T_crank / (i13 · η_g)
```

其中 `η_g=0.9319` 是轮系效率，`η_l=0.90` 是曲柄摇杆等效效率。

当前曲线图已经对 `M_aero` 做了周期 Hann 窗平滑处理。这样处理的目的，是把气动分段公式造成的小尖角近似为真实流场中的连续过渡；四杆机构换向和高加速度造成的大趋势仍然保留。

## 三、关键角度与实际运动阶段

| 曲柄角范围 | 机构状态 | 摇杆运动 | 读图重点 |
|:---|:---|:---|:---|
| `0°~83.5°` | 接近小摆角端 | `φ` 减小，速度逐渐降到 0 | 机构在制动摇杆，准备换向 |
| `83.5°` | 小摆角端换向 | `φ_dot≈0` | 力矩可能明显，但功率不一定大 |
| `83.5°~148°` | 从小摆角端离开 | `φ` 增大，正向加速 | 惯性力矩上升，机构把翅膀甩起来 |
| `148°~188°` | 向大摆角端快速摆动 | `φ_dot` 继续增大 | 摇杆速度高，功率开始变大 |
| `188°~238.5°` | 接近大摆角端 | `φ` 仍增大，但开始减速 | 225.5° 附近角加速度负峰值，制动扭矩绝对值最大 |
| `238.5°` | 大摆角端换向 | `φ_dot≈0` | 外载力矩（M_wing）绝对值达峰值，但功率被速度项压低 |
| `238.5°~308.5°` | 从大摆角端返回 | `φ` 减小，速度逐渐增大 | 174.0° 附近正扭矩峰（驱动），227.5° 附近负扭矩峰（制动） |
| `308.5°~360°` | 返回后半段到小摆角端 | `φ_dot` 负向速度在 308.5° 达最大 | 逐步进入下一圈小摆角端换向 |

## 四、摇杆端等效外载力矩图

![摇杆端等效外载力矩](../figures/rocker_moment_vs_crank_angle.png)

这张图画的是作用在摇杆端的等效外载力矩：

```text
M_wing = M_aero + M_inertial
M_inertial = I_w · φ_ddot
```

### 0°~83.5°

摇杆正在向小摆角端运动，`φ` 从约 `30.5°` 减小到 `15.2°`。此时 `φ_dot<0`，但逐渐接近 0，说明摇杆正在被机构减速。图中惯性力矩偏正，对应实际运动就是翅膀快到端点，需要被机构制动并准备反向。

### 83.5°附近

这是小摆角端换向点。`φ_dot≈0`，所以摇杆端虽然仍有外载力矩，但它对应的瞬时功率不一定大。这里更应该看作“换向位置”，不是电机最大负载位置。

### 83.5°~188°

摇杆离开小摆角端，`φ` 增大。先是正向加速，然后速度逐渐升高。`148°` 附近角加速度达到正峰值，所以惯性力矩出现明显上升；`188°` 附近速度最大，对应翅膀通过中段的高速运动。

### 188°~238.5°

摇杆继续向大摆角端摆动，但开始减速。`225.5°` 附近角加速度达到负峰值，说明机构正在强烈制动摇杆，让它停在大摆角端。因此惯性力矩会向负方向急剧变化。

### 238.5°~242.0°

摇杆刚到达大摆角端换向点（`238.5°`），`φ_dot` 过零。此时气动项和惯性项方向一致，`M_wing` 的绝对值在 `242.0°` 附近达到最大：

```text
M_wing_peak ≈ 1503.04 N.mm
```

这个峰值紧邻大摆角端换向点，对应翅膀在大摆角端承受最大外载。但由于 `φ_dot≈0`，瞬时功率不大——这个峰值对应的是”摇杆端外载最大”，不是”电机扭矩最大”。

### 242.0°~360°

摇杆继续向小摆角端返回。外载力矩从大峰值逐渐回落。到 `308.5°` 附近，摇杆负向速度最大，但外载已经下降，所以摇杆端力矩图不再保持最大。

## 五、曲柄轴与电机轴扭矩图

![曲柄轴与电机轴扭矩](../figures/torque_chain_vs_crank_angle.png)

这张图不是直接画 `M_wing`，而是通过功率等效换算：

```text
P = M_wing · φ_dot
T_crank = P / (ω_crank · η_l)
T_motor = T_crank / (i13 · η_g)
```

所以读这张图时要同时看两个因素：

```text
M_wing 是否大
φ_dot 是否大
```

只有外载力矩大、摇杆速度也大时，曲柄轴扭矩才容易达到峰值。

### 0°~83.5°

摇杆向小摆角端运动，`φ_dot<0`。此时 `M_wing>0`（气动阻力与运动反向），`P=M_wing·φ_dot<0`，曲柄轴扭矩为负，表示该瞬时翅膀载荷对曲柄转动有助推或回馈趋势。实际运动对应的是翅膀被推向小摆角端点，电机不处于最大正向驱动状态。

### 83.5°~148°

摇杆从小摆角端换向离开，`φ_dot>0` 且逐渐增大。`M_wing` 仍为正（翅膀受气动阻力），因此 `P=M_wing·φ_dot>0`，曲柄轴扭矩为正——电机需要输入正功率来推动翅膀克服气动阻力。`148°` 附近角加速度达到正峰值（5053.5 rad/s²），惯性力矩贡献明显。

### 148°~188°

摇杆持续加速，`188°` 附近 `φ_dot` 达到正峰值（69.25 rad/s）。此区间内气动阻力随速度平方增大，`M_wing` 保持正值，曲柄轴扭矩在 `173.5°` 附近达到正向峰值：

```text
θ ≈ 173.5°
T_crank_peak ≈ 239.86 N.mm
T_motor_peak ≈ 7.88 N.mm
```

这个正峰是电机需要输出最大正向驱动扭矩的位置。实际运动对应翅膀在高气动负载下被机构加速推向大摆角端。

### 188°~238.5°

摇杆接近大摆角端，开始强烈减速。`225.5°` 附近 `φ_ddot` 达到负峰值（-12374.7 rad/s²），惯性力矩急剧反向。`M_wing` 由正转负（气动阻力+惯性制动同向），`φ_dot` 仍为正，因此 `P=M_wing·φ_dot<0`，曲柄轴扭矩为负——翅膀在制动机构。`227.5°` 附近达到负向峰值：

```text
θ ≈ 227.5°
T_crank ≈ -353.83 N.mm
T_motor ≈ -11.63 N.mm
```

这个负峰的绝对值大于正峰，但对应的是制动工况（翅膀减速），不是电机主动输出最大正扭矩。

### 238.5°~360°

摇杆从大摆角端换向返回，`φ_dot<0`。刚换向时 `M_wing` 绝对值很大（`242.0°` 附近达到峰值），但速度尚低。随着速度增大，`M_wing` 逐渐减小。`308.5°` 附近 `φ_dot` 达到负向最大速度（-43.56 rad/s），此时曲柄轴扭矩在 `271.0°` 附近出现第二个正峰（约 193.86 N.mm），但幅值低于前向摆动正峰。此后扭矩逐步回落，进入下一圈小摆角端换向。

## 六、齿轮啮合力图

![齿轮啮合力随曲柄转角变化](../figures/gear_mesh_forces_vs_crank_angle.png)

齿轮啮合力由扭矩换算：

```text
Ft = 2T / d
Fr = Ft · tanα
Fn = Ft / cosα
```

这张图画的是力的大小，所以和曲柄轴、电机轴扭矩的绝对值趋势基本一致，不保留正负号。

### 为什么第二级更大

第二级齿轮 2'-3 靠近输出轴，承担的是减速后的较大输出扭矩，所以第二级啮合力明显大于第一级。

当前峰值为：

| 啮合副 | Ft | Fr | Fn | 对应状态 |
|:---|---:|---:|---:|:---|
| 齿轮 1-2 | 11.074 N | 4.031 N | 11.785 N | 电机端输入齿轮处峰值 |
| 齿轮 2'-3 | 58.971 N | 21.464 N | 62.756 N | 输出级靠近曲柄轴，载荷最大 |

### 峰值为什么在 227.5° 附近

齿轮啮合力由扭矩绝对值决定。`227.5°` 附近曲柄轴扭矩绝对值达峰值（-353.83 N.mm），因此齿轮啮合力也在此处达到最大。实际运动状态是翅膀接近大摆角端、机构强烈制动，气动阻力和惯性制动同向叠加，使外载扭矩绝对值最大。因此齿轮齿面接触力、轴承径向载荷也在这里达到最大。

## 七、读图时最容易混淆的点

1. `M_wing` 峰值不等于 `T_crank` 峰值。  
   `M_wing` 只看摇杆端外载；`T_crank` 看的是功率等效，即 `M_wing · φ_dot`。

2. 换向点不一定是电机最吃力点。  
   换向点附近 `φ_dot≈0`，即使力矩明显，功率也可能被速度项压低。

3. 齿轮啮合力图画的是力的大小。  
   所以它不会显示正负方向，而是跟扭矩绝对值走。

4. 需要区分两种"最吃力"的工况。  
   - 摇杆端外载最大：`238.5°~242.0°`（大摆角端换向附近，M_wing ≈ 1503.04 N.mm）
   - 曲柄轴/齿轮力最大：`227.5°` 附近（制动区，T_crank ≈ -353.83 N.mm，齿轮力达峰值）
   - 电机正向驱动扭矩最大：`173.5°` 附近（前向摆动高负载区，T_crank ≈ 239.86 N.mm）

## 八、一句话读图

这三张线图可以按下面这条实际运动链理解：

```text
小摆角端换向 83.5°
→ 摇杆加速摆向大摆角端，173.5° 电机正向驱动扭矩最大
→ 大摆角端前强制减速，227.5° 制动扭矩和齿轮力绝对值最大
→ 大摆角端换向 238.5°，M_wing 外载达峰值
→ 返回中段，271.0° 出现第二个正扭矩峰（幅值较低）
→ 返回后半段载荷下降
→ 下一圈小摆角端换向
```
