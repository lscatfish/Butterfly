# 心得体会

本次分析最大的体会是：机械原理中的轮系、四杆机构、受力分析并不是孤立知识点。对于扑翼飞行器，气动力模型的一个攻角定义错误，最终会传导到摇杆外载、曲柄扭矩和齿轮啮合力；而机构参数中$a$�?R$的含义混淆，也会直接影响运动学摆幅和急回特性。因此，机械设计需要把坐标系、参数定义、程序输出和图纸结构一一对应�?
另一方面，解析法相比数值法具有明显优势。在四连杆机构运动学分析中，位置、速度、加速度三阶段共用同一系数矩阵$\mathbf{M}$，仅需一次矩阵求逆，计算效率高且避免了数值微分的截断误差。这一特点在高频扑动（17Hz）下尤为重要�?
仿生机构往往具有强非线性。简单追求更高的升重比可能把模型推到非物理区间，得到看似漂亮但不可制造、不可验证的结果。本报告在气动章节加入平均攻角和失速占比约束，在机械章节加入峰值扭矩和齿轮力校核，就是为了让设计结果同时经得起物理解释和机构实现�?
