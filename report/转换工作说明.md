### 未完成 / 已知问题

** 行内公式未转换（最关键问题）**

pandoc 将 `$$...$$`（块公式）正确转换为 Word OMML 公式（172个，全部成功），但 `$...$`（行内公式）**没有转换为 OMML**，而是被当作纯文本处理，LaTeX 标记被丢弃。

例如 md 中写：
```
模数$m=0.3\mathrm{mm}$，压力角$\alpha=20°$
```

docx 中变成：
```
模数，压力角，齿顶高系数，顶隙系数。
```

公式内容完全丢失，只剩下中文文本。

**原因**：pandoc 的 `--from=markdown+tex_math_dollars` 只处理 `$$...$$` 块公式，不处理 `$...$` 行内公式。尝试过 `--mathjax` 和 `+tex_math_single_backslash` 均无效。

**可能的解决方案**（需后续 AI 尝试）：
1. 将所有 `$...$` 行内公式改为 `$$...$$` 块公式（简单但影响排版，公式会单独成行）
2. 使用 pandoc 的 `--from=markdown+tex_math_dollars+tex_math_single_backslash` 并确保 `$` 不被其他解析器吞掉
3. 放弃 pandoc，改用 python-docx 直接构建文档（工作量大但完全可控）
4. 用 `pandoc --to=html` 先转 HTML 检查行内公式是否保留，再找中间方案

## 3. 各文件功能说明

### 转换脚本：`convert_to_docx.py`

三步流程：
1. **合并 md**：按章节顺序拼接所有 md 文件，将相对图片路径转为绝对路径
2. **pandoc 转换**：`pandoc md→docx`，处理 LaTeX 公式→OMML、图片插入、表格生成
3. **python-docx 后处理**：
   - 页面设置（A4，页边距）
   - 字体（宋体/黑体/Times New Roman，全部黑色）
   - 字号（章标题16pt，节标题15pt，正文12pt等）
   - 行距（固定20磅）、首行缩进（2字符）
   - 页眉（"机械原理大作业"）+ 页脚（页码）
   - 三线表格式化
   - 图片宽度限制（≤14cm）
   - 公式字体（Cambria Math）

### 图片资源

| 来源 | 位置 | 用途 |
|------|------|------|
| 齿轮docx | `unpacked_gear/word/media/` | 图3-1(a/b)、图3-2、图7-1 |

| Python生成 | `output/figures/` | 图1-1、图4-2、图4-3、图6-1~6-5等 |

### 格式要求参考

`格式要求/` 目录包含学校模板和7张截图，关键要求：
- 章标题：三号黑体居中
- 节标题：小三号黑体左对齐
- 条标题：四号黑体左对齐
- 正文：小四号宋体，固定行距20磅，首行缩进2字符
- 公式：居中，编号右对齐，Cambria Math 字体
- 表格：三线表（有合计用四线表）
- 图题/表题：五号宋体居中
- 页眉：小五号宋体居中
- 页脚页码：小五号 Times New Roman 居中

# 列出所有 md 中的图片引用
cd report; Select-String -Pattern "!\[" -Path *.md
